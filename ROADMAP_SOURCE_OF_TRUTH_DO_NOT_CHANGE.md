# 🟢 1️⃣ Task Understanding Layer

Purpose: Convert messy input into structured execution data.

User types:

> “Call accountant about overdue tax stuff”

AI extracts:

```json
{
  "task_type": "administrative",
  "cognitive_load": "light",
  "emotional_weight": "high",
  "estimated_duration": 15,
  "ambiguity_level": 7,
  "external_dependency": true
}
```

Use LLM prompt engineering for classification.

This runs:

* On task creation
* On major edits

Model: Small fast LLM (cost-efficient).

---

# 🟢 2️⃣ Friction Scoring Layer (Core Engine)

This is your moat.

Score formula (initial version):

```
Friction Score =
  (Ambiguity × 0.3)
+ (Emotional Weight × 0.4)
+ (Cognitive Load × 0.2)
+ (History Avoidance × 0.5)
```

Output: 1–10 Activation Energy Score.

If score > threshold → trigger shrink protocol.

This doesn’t require ML at first.
It’s deterministic + AI classification.

---

# 🟢 3️⃣ Intervention Generation Layer

This is where LLM shines.

Prompt design:

“Break this task into the smallest possible physically executable first action that requires less than 2 minutes.”

Example output:

> Open email.
> Search accountant name.
> Do not send yet.

Or:

“Generate a friction-reducing script for a difficult phone call.”

AI generates:

* Micro-start
* Script
* Checklist
* 90-second start plan

Important:
LLM never plans full day.
Only generates execution micro-actions.

# 🟢 4️⃣ Adaptive Learning Layer (Keep It Simple)

Simple rules > premature ML.
